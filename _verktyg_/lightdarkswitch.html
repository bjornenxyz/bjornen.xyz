Välkommen

Denna sida demonstrerar en modern light/dark mode switcher med CSS variabler. Klicka på switchen i headern för att byta tema.

Funktioner

Denna design innehåller:

  • Sticky header som stannar längst upp
  • Snygg och modern theme switcher
  • CSS variabler för enkel temning
  • Smooth transitions mellan teman
  • Tillgänglig design med ARIA labels

Design

Designen är skapad för att vara:

  • Responsiv och mobilvänlig
  • Snabb och effektiv
  • Lätt att anpassa med CSS variabler
  • Tillgänglig för alla användare

Hur det fungerar

Switchen använder CSS variabler för att definiera färger. Genom att ändra attributet data-theme på html-elementet uppdateras alla färger automatiskt.
